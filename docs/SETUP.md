# 配置、更新与回滚

## 三种配置分开维护

1. 全局 prompt：每台执行设备自己的 ~/.codex/AGENTS.md；本仓库通用规则与对应平台规则合并生成。
2. 项目事实与约定：项目 README、背景资料和可选 AGENTS.md，可随项目 Git 同步。
3. 机器设置：模型、权限、插件、代理、登录和 SSH，由该设备设置与官方配置管理；不放入公共 prompt 仓库。

Windows 默认目录为 %USERPROFILE%\.codex，macOS/Linux 为 ~/.codex。若自定义 CODEX_HOME，安装器和启动 Codex 的环境必须一致。

## 备份和回滚

安装前若目标存在，会在同目录生成 AGENTS.md.backup-*（PowerShell）或 AGENTS.md.backup.*（shell）。手动选择所需备份复制回 AGENTS.md，再新开聊天。备份可能含私人内容，不提交到仓库。
安装器替换整个 AGENTS.md，而不尝试合并任意用户手写规则。先预演并确认源文件内容；长期偏好应维护在本仓库。

## 排查规则未生效

确认聊天执行位置、账户、CODEX_HOME 和目标路径；检查项目或更深目录是否有补充规则。编辑仓库文件后需要重新安装，不会自动传播到已运行的所有聊天。

## SSH 与网络

SSH 免密只解决服务器登录；Codex 账号登录与访问模型是独立检查项。分别检查 ssh、codex --version、codex login status 以及实际模型请求。
不要提交私钥、认证 JSON 或代理 .env。Mac/Windows 各自生成私钥，仅向服务器追加公钥。远端 127.0.0.1 与桌面端不是同一地址；临时隧道关闭后不再提供网络。

## 建议模型习惯

日常选择账户当前可用的通用主力模型与中等推理强度；复杂排错再提高强度或选择更强模型。模型名称、额度和可用性会变化，因此不在共享安装器中写死 model 或自动覆盖 config.toml。
